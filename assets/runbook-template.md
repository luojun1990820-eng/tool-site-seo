# 工具站项目运行手册

一个工具站从头到尾一张表。复制到项目根目录（建议 `.project/runbook.md`），每完成一段就把空格填掉。

**规矩**：一次只推进一段；填不出的格子写 `not assessed` 并注明缺什么数据，不要估。

```
Vet ──→ Spec ──→ Gate ──→ Launch ──→ Diagnose ──↺──→ Grow
 立项     规格     上线前    头90天      改版/掉排名     增长
```

## 2. Spec — 页面规格

| 类型 | URL | 目标词 | 搜索量 | 独有内容来源 | 优先级 |

| 解释页 | `/what-is/____` | | | | P2 |

### 2.2 结构约定

- 子目录，不用子域名
- 尾部斜杠策略：____（有 / 无），301 统一
- 任一工具页 ≤ 3 次点击可达
- 每页入链 ≥ 3：目录 + 相关工具 ____ + 解释页 ____
- 面包屑：____

### 2.3 结果页索引策略

| 情形 | 处理 |
|---|---|
| 工具页默认结果 | 服务端渲染进 HTML |
| 交互态 `?a=1&b=2` | `noindex` + canonical 到干净 URL |
| 高搜索量固定组合 | 单独静态页（需过 §2.4 白名单） |
| 分享结果链接 | `noindex` |

### 2.4 组合页白名单与批次

| 项 | 值 |
|---|---|
| 候选组合总数 | |
| 通过需求验证的数量 | |
| 验证口径（搜索量 ≥ ___ / GSC 曝光 ≥ ___） | |
| 批次大小（50–100） | |
| 批间隔观察期（2–4 周） | |
| 人工抽检比例（5–10%） | |

**闸门**：两页间独有内容 <30% 整批打回；30–40% 补内容；未审 100 页警告；500 页硬停。

### 2.5 sitemap 拆分

```
/sitemap.xml（index）
├── sitemap-tools.xml
├── sitemap-convert.xml（仅白名单）
├── sitemap-compare.xml
├── sitemap-explainers.xml
└── sitemap-blog.xml
```

单个 ≤ 50,000 URL 且 ≤ 50MB；`lastmod` = 实质变更日期；不放 noindex / 跳转 / 非 canonical。

### 2.6 工具页模板（八块，按序）

1. H1 = 查询词
2. 工具本体（移动端首屏可见输入）
3. 结果（真实 HTML，带单位）
4. 原理 / 公式（含确切系数）
5. 算例 3–5 个
6. FAQ 5–7 条（40–60 词直答）
7. 相关工具 3–8 个
8. 最后更新日期

**下限**：关掉 JS 后可见正文 ≥ 150 词（<150 警告，<50 且为 JS 壳 = 不合格）。

## 5. Diagnose — 异常诊断

**触发**：改版上线 ｜ 收录率下降 ｜ 排名掉 ｜ 流量掉

| 项 | 内容 |
|---|---|
| 触发日期 | |
| 现象 | |
| 最近一次变更 | 模板 / 数据 / 域名 / 外链 / 无 |
| 影响范围 | ___ 页（哪类页面） |

### 5.1 顺序排查（找到原因就停）

1. **收录了吗**：GSC URL 检查 10 个重点页 → coverageState = ______
   - "Discovered – not indexed" → 抓取优先级问题
   - "Crawled – not indexed" → 质量问题
   - "Duplicate / Alternate page with proper canonical" → 组合页塌陷
2. **变了吗**：对基线做 diff（见 5.2）
3. **外部原因**：对照已确认的更新日期（台账 >30 天未核验就别引用）
4. **抓取预算**：sitemap 是否等于可索引集；空组合是否返回 404

### 5.2 漂移 diff（对每个页面类型跑一行）

| 规则 | 基线 | 当前 | 命中 | 严重度 |
|---|---|---|---|---|
| canonical 变更/消失 | | | | 严重 |
| 新增 noindex | | | | 严重 |
| 状态 2xx→4xx/5xx | | | | 严重 |
| 结果块从 HTML 消失 | | | | 严重 |
| schema 消失或哈希变 | | | | 严重/警告 |
| H1 消失或差异 >50% | | | | 严重/警告 |
| 标题消失或变更 | | | | 严重/警告 |
| CWV 回退 >20% | | | | 警告 |
| 入链 <3 | | | | 警告 |

**结论**：☐ 代码/模板问题　☐ 内容质量　☐ 抓取预算　☐ 外部更新　☐ 无法判定（缺：____）
